# estudioSI — sitio web

Este repositorio contiene solo los archivos estáticos necesarios para publicar la aplicación con GitHub Pages. El código fuente completo y los CSV de relevamiento permanecen en el repositorio privado `estudioSI`.

Los datos visibles proceden de la Cartilla pública de PAMI. Que una sede figure para una categoría no confirma que realice una práctica específica ni que tenga disponibilidad actual.
